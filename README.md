# دمو رزرو روز و ساعت با Flask

یک سایت نمونه برای انتخاب روز و ساعت قرار ملاقات، با ثبت رزروها در SQLite.

## اجرا روی سیستم

```bash
python -m venv .venv
# ویندوز:
.venv\Scripts\activate
# مک / لینوکس:
source .venv/bin/activate
pip install -r requirements.txt
python app.py
```

سپس مرورگر را باز کنید: `http://127.0.0.1:5000`

## انتشار در Render

1. همه‌ی فایل‌ها را در یک Repository گیت‌هاب آپلود کنید.
2. در Render گزینه‌ی **New > Web Service** را بزنید و Repository را انتخاب کنید.
3. پلن **Free** را انتخاب کنید.
4. تنظیمات را از `render.yaml` تأیید و Deploy کنید.

## مسیرها

- `/` صفحه رزرو
- `/success` تأیید رزرو
- `/admin` فهرست رزروها (فقط برای دمو؛ در نسخه واقعی با رمز محافظت شود)
- `/health` وضعیت سرویس

> نکته مهم: SQLite روی فضای دیسک موقت سرویس‌های رایگان ممکن است پس از Redeploy یا ری‌استارت پاک شود. برای یک نمونه‌ی کوتاه‌مدت مناسب است؛ برای سایت واقعی از PostgreSQL استفاده کنید.
